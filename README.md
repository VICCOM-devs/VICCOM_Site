# viccom.se

Static site on GitHub Pages. Every commit to `main` deploys.

## Languages
English is the main language (repo root). Swedish lives in `sv/`.
The Swedish privacy policy and delete-account pages stay at the root
(`integritetspolicy.html`, `radera-konto.html`) because those URLs are registered in Google Play Console.

| Page | English | Swedish |
|---|---|---|
| Home | `/` | `/sv/` |
| Wobble Wheels | `/wobble-wheels.html` | `/sv/wobble-wheels.html` |
| Wyrmwind | `/wyrmwind.html` | `/sv/wyrmwind.html` |
| AnyLap | `/anylap.html` | `/sv/anylap.html` |
| Psst | `/psst.html` | `/sv/psst.html` |

| Web build of Wobble Wheels | `/play/` | – |

## Editing
The HTML pages are generated. **Edit `_src/build.py`, then run `python3 _src/build.py`** from the repo root
and commit the result. Every text exists as an English/Swedish pair, so both languages,
menus and footers stay in sync. Hand edits to the generated `.html` files are overwritten on the next build.

- Product status, badge text and progress meter: the `PRODUCTS` list at the top of `_src/build.py`.
- At Wobble Wheels launch: set `status` to `live`, change the badge, set `meter` to 100,
  and add the Google Play link to its `cta` list.
- After changing `style.css` or `frost.js`: bump `CSS_V` so browsers fetch the new file.

`play/` (the Wobble Wheels web build) is not generated by this script.

## Design
Frozen mist palette, dark. Tokens at the top of `style.css`. Fonts Unbounded + Familjen Grotesk, self-hosted (OFL).
